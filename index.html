Hi, I'm Saswat.

I build things with machine learning and large language models: memory layers for AI agents, voice agents, and small tools that make everyday work a little less painful. Most of what I know, I learned by building it and pushing it to GitHub, which is still the best place to see what I'm up to.

theme:

I started out working through the maths: Stanford's CS229 problem sets, neural networks written from scratch, RNNs and transfer learning in notebooks. Then I kept going one layer up: data pipelines, backends, full-stack apps, and lately agents that remember things, talk in Hinglish, and call tools. Every one of those taught me something I'd like to keep. This website is where I'm writing it down, so that a few years from now I can open it and remember how things actually work.
